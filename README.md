# movie-service

Kotlin Spring Boot service that owns movies, credits and artwork. It serves the GraphQL API used by `movie-web` and calls `people-service` over gRPC, using the contract in the `protos` submodule at `proto/`.

## Clone

```
git clone --recurse-submodules https://github.com/BenWanLH/movie-service.git
```

Setup and run instructions will be added as the service is built.
